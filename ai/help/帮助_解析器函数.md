'''解析器函数'''（ParserFunction）是<code>MediaWiki</code>系统中的重要组成部分，这是MediaWiki系统区别于其他维基类软件和CMS系统（例如WordPress）的最大不同之一。解析器函数简单来说就是通过特定的语法来（<nowiki>{{#}}</nowiki>）调用PHP的底层函数，进行逻辑表达或是运算，实现一些复杂的功能和效果。典型语法是：
:<code><nowiki>{{</nowiki>#函数名: 参数1 | 参数2 | 参数3 …}}</code>
*各函数名都对大小写不敏感。
*语句中的空格、换行等空白字符将被省略。
*解析器函数实际上是MarkUp[[wiki标记语言|维基语言]]的一部分，同样需要由MediaWiki的解析器进行转译（Parser），因此运行效率受到一定限制。
**由Module提供的Lua脚本可以更高效的执行函数逻辑，可以全面取代解析器函数。

==扩展==
MediaWiki的解析器函数全部由扩展提供，扩展'''Extension:ParserFunctions'''现在是MediaWiki的基础部分，带有预设的基本函数：<code><tt>expr</tt></code>，<code><tt>if</tt></code>，<code><tt>ifeq</tt></code>，<code><tt>ifexpr</tt></code>，<code><tt>iferror</tt></code>，<code><tt>rel2abs</tt></code>，<code><tt>titleparts</tt></code>，<code><tt>switch</tt></code>等。

其他函数需要通过特定的插件提供，有些函数例如Loop循环等出于性能考虑灰机不予提供支持，可以通过[[帮助:模块|Lua脚本]]来实现。

===if ===
<code>if</code><函数是一个if-then-else结构。语法是：

 <nowiki>{{</nowiki>#if: ''&lt;判断字符串>'' | ''&lt;then字符串>'' | ''&lt;else字符串>'' }}
 <nowiki>{{</nowiki>#if: ''&lt;判断字符串>'' | ''&lt;then字符串>'' |}}

若判断字符串为非空字符串（忽略前导或后缀空格），则函数返回then字符串，否则函数返回else字符串。else字符可被省略而不会造成错误，但函数在判断字符串为空时便会返回空字符串。

===ifeq ===
<code>ifeq</code>比较两个字符串，返回比较结果。语法为：

 <nowiki>{{</nowiki>#ifeq: ''&lt;字符串1>'' | ''&lt;字符串2>'' | ''&lt;相等时返回的字符串>'' | ''&lt;不相等时返回的字符串>'' }}

注意：两个空字符串是相等的。

示例：

假设模板Ifeq test的内容是
 <nowiki>{{#ifeq:{{{lang}}}|zh|我使用中文|I don't use Chinese}}</nowiki>

则<nowiki>{{Ifeq test|lang=zh}}</nowiki>的结果是'''我使用中文'''；而<nowiki>{{Ifeq test|lang=en|I prefer English}}</nowiki>的结果是'''I don't use Chinese'''。

===ifexist ===
<code>ifexist</code>会判断指定的页面是否存在，然后返回对应的文字:
 &#123;{#ifexist: ''&lt;待测页面标题>'' | ''&lt;存在文字>'' | ''&lt;不存在文字>'' }}

示例：

*&#123;{#ifexist:test|有test頁面|無test頁面}&#125; 得到'''{{#ifexist:test|有test頁面|無test頁面}}'''
*&#123;{#ifexist:User:Sex|該用戶頁存在|該用戶頁不存在}&#125; 得到 {{#ifexist:user:sex|該用戶頁存在|該用戶頁不存在}}
*&#123;{#ifexist:维基百科|'''√'''|'''×'''}&#125; 得到 {{#ifexist:维基百科|'''√'''|'''×'''}}

===ifexpr ===
<code>ifexpr</code>计算数学表达式，并根据计算结果返回字符串。

 <nowiki>{{</nowiki> #ifexpr: ''&lt;表达式>'' | ''&lt;表达式不为0的结果>'' | ''&lt;表达式为0的结果>'' }}

表达式语法与<tt>expr</tt>相同。

===iferror===
 <nowiki>{{#iferror:</nowiki> ''测试表达式'' | ''出错时显示结果'' | ''正确运算时显示结果'' }}

:<code><nowiki>{{#iferror: {{#expr: 1 + 2 }} | error | correct }}</nowiki></code> → '''{{#iferror: {{#expr: 1 + 2 }} | error | correct }}'''
:<code><nowiki>{{#iferror: {{#expr: 1 + X }} | error | correct }}</nowiki></code> → '''{{#iferror: {{#expr: 1 + X }} | error | correct }}'''
:<code><nowiki>{{#iferror: {{#expr: 1 + 2 }} | error }}</nowiki></code> → '''{{#iferror: {{#expr: 1 + 2 }} | error }}'''
:<code><nowiki>{{#iferror: {{#expr: 1 + X }} | error }}</nowiki></code> → '''{{#iferror: {{#expr: 1 + X }} | error }}'''
:<code><nowiki>{{#iferror: {{#expr: 1 + 2 }} }}</nowiki></code> → '''{{#iferror: {{#expr: 1 + 2 }} }}'''
:<code><nowiki>{{#iferror: {{#expr: 1 + X }} }}</nowiki></code> → '''&zwnj;{{#iferror: {{#expr: 1 + X }} }}'''<!-- maybe the zwnj protects the trailing space before no output -->
:<code><nowiki>{{#iferror: {{#expr: . }} | error | correct }}</nowiki></code> → '''{{#iferror: {{#expr: . }} | error | correct }}'''
:<code><nowiki>{{#iferror: <strong class="error">a</strong> | error | correct }}</nowiki></code> → '''{{#iferror: <strong class="error">a</strong> | error | correct }}'''

=== #rel2abs ===
<code>rel2abs</code>函数将页面的相对路径转化为绝对路径

:<code><nowiki>{{#rel2abs:</nowiki> ''路径'' <nowiki>}}</nowiki></code>
:<code><nowiki>{{#rel2abs:</nowiki> ''路径'' <nowiki>|</nowiki> ''Base路径'' <nowiki>}}</nowiki></code>


输入合法的<code>路径</code>后，具体的语法为：
*<code>.</code> → 本层
*<code>..</code> → 上一层
*<code>/foo</code> → 指定到名为“foo”的那一层


如果 <code>Base路径</code>未指定，默认使用完整的页面路径<nowiki>{{FULLPAGENAME}}</nowiki>

:<code><nowiki>{{#rel2abs:</nowiki> /quok | {{ns:12}}:Foo/bar/baz <nowiki>}}</nowiki></code> → '''{{#rel2abs: /quok | {{ns:12}}:Foo/bar/baz }}
:<code><nowiki>{{#rel2abs:</nowiki> ./quok | {{ns:12}}:Foo/bar/baz <nowiki>}}</nowiki></code> → '''{{#rel2abs: ./quok | {{ns:12}}:Foo/bar/baz }}
:<code><nowiki>{{#rel2abs:</nowiki> ../quok | {{ns:12}}:Foo/bar/baz <nowiki>}}</nowiki></code> → '''{{#rel2abs: ../quok | {{ns:12}}:Foo/bar/baz }}
:<code><nowiki>{{#rel2abs:</nowiki> ../. | {{ns:12}}:Foo/bar/baz <nowiki>}}</nowiki></code> → '''{{#rel2abs: ../. | {{ns:12}}:Foo/bar/baz }}

====转义与特例====
<code>/.</code> or <code>/./</code>,等非法字符会被忽略，其他情况参考下列实例

:<code><nowiki>{{#rel2abs:</nowiki> ../quok/. | {{ns:12}}:Foo/bar/baz <nowiki>}}</nowiki></code> → '''{{#rel2abs: ../quok/. | {{ns:12}}:Foo/bar/baz }}
:<code><nowiki>{{#rel2abs:</nowiki> ../../quok | {{ns:12}}:Foo/bar/baz <nowiki>}}</nowiki></code> → '''{{#rel2abs: ../../quok | {{ns:12}}:Foo/bar/baz }}
:<code><nowiki>{{#rel2abs:</nowiki> ../../../quok | {{ns:12}}:Foo/bar/baz <nowiki>}}</nowiki></code> → '''{{#rel2abs: ../../../quok | {{ns:12}}:Foo/bar/baz }}
:<code><nowiki>{{#rel2abs:</nowiki> ../../../../quok | {{ns:12}}:Foo/bar/baz <nowiki>}}</nowiki></code> → '''{{#rel2abs: ../../../../quok | {{ns:12}}:Foo/bar/baz }}

===switch ===
<code>switch</code>将一个值与多个预设值比较，若有匹配时则返回指定字符串，即[[双射]]。语法是：

 <nowiki>{{</nowiki> #switch: ''&lt;比较值>''
 | ''&lt;预设值1>'' [= ''&lt;结果1>'']
 | ''&lt;预设值2>'' [= ''&lt;结果2>'']
 | ''...''
 | ''&lt;预设值n>'' [= ''&lt;结果n>'']
 | [#default = ]''&lt;缺省结果>'' 
 }}

<code>switch</code>将从左往右逐一尝试，直到出现匹配。函数将返回第一个匹配值对应的结果，而忽略后面的匹配值。如果没有匹配，函数将返回缺省结果。如果缺省结果没有设置，函数将返回空串。

注意：“缺省结果”是'''最后一个没有等号'''的预设值或“#default”预设值对应的结果；如果期望把一个包含“=”号的字符串作为缺省结果，则必须采用“#default”预设值形式。例如：
 <nowiki>#default = <span style</nowiki><span style="color:red;">=</span><nowiki>"color:red;">red</span></nowiki>

<code>switch</code>也可用作'''满射'''（多对一，避免重复设置结果）。即某预设值后未设置结果，这样如果该预设值与比较值匹配，则函数返回'''第一个有结果的'''预设值的结果。例如：

 <nowiki>{{</nowiki> #switch: ''&lt;比较值>''
 | ''&lt;预设值1>''
 | ''&lt;预设值2>''
 | ''&lt;预设值3>'' = ''&lt;结果3>''
 | ''&lt;缺省结果>''
 }}
如果比较值与预设值1、预设值2或预设值3匹配，都将返回结果3。注意：“#default”后必须有“=”，但其他预设值可以使用“#default”的结果。

系统默认的时间参数为当前UTC+0时间，可以使用<code>{&#123;#time:参数|+8 hours}}</code>得到当前北京时间（UTC+8时间）。

时间参数可以使用绝对时间，如“<code>2008-12-31 23:59:59</code>”，也可以使用相对时间，如“<code>+7 days</code>”或者“<code>-5 hours</code>”得到默认时间7日之后或默认时间5小时之前的时间。也可以二者混合使用，比如<code>{&#123;#time:Y-m-d H:i:s|2001-2-3 04:05:06 +1 year +2 months +3 days +4 hours +5 minutes +6 seconds}}</code>返回
'''{{#time:Y-m-d H:i:s|2001-2-3 04:05:06 +1 year +2 months +3 days +4 hours +5 minute +6 seconds}}'''

使用<code>xr</code>可以在其后显示罗马数字，如<code>{&#123;#time:'''xr'''Y年'''xr'''m月'''xr'''d日|2008-12-31}}</code>显示为'''{{#time:xrY年xrm月xrd日|2008-12-31}}'''

=== titleparts ===
此函数将页面标题根据斜杠划分成多个分段，然后返回这些分段中的某些部分做为输出。
<code><nowiki>{{#titleparts:</nowiki> ''pagename'' <nowiki>|</nowiki> ''number of segments to return'' <nowiki>|</nowiki> ''first segment to return'' <nowiki>}}</nowiki></code>

如果没有指定要返回的分段数量参数，则默认为“0”，会返回从要返回的第一个分段一直到结尾（有包含）的所有分段。如果要返回的第一个分段参数没有指定或者为“0”，则默认为“1”。

: <code><nowiki>{{#titleparts:</nowiki> <span style="color: blue;">{{ns:1}}:Foo/bar/baz/quok</span> <nowiki>}}</nowiki></code> → '''{{#titleparts: {{ns:1}}:Foo/bar/baz/quok }}'''
: <code><nowiki>{{#titleparts:</nowiki> <span style="color: blue;">{{ns:1}}:Foo</span>/bar/baz/quok <nowiki>| 1 }}</nowiki></code> → '''{{#titleparts: {{ns:1}}:Foo/bar/baz/quok | 1 }}''' <small>See also <nowiki>{{</nowiki>[[Help:魔术字#Page_names|ROOTPAGENAME]]<nowiki>}}</nowiki>.</small>
: <code><nowiki>{{#titleparts:</nowiki> <span style="color: blue;">{{ns:1}}:Foo/bar</span>/baz/quok <nowiki>| 2 }}</nowiki></code> → '''{{#titleparts: {{ns:1}}:Foo/bar/baz/quok | 2 }}'''
: <code><nowiki>{{#titleparts:</nowiki> {{ns:1}}:Foo/<span style="color: blue;">bar/baz</span>/quok <nowiki>| 2 | 2 }}</nowiki></code> → '''{{#titleparts: {{ns:1}}:Foo/bar/baz/quok | 2 | 2 }}'''
: <code><nowiki>{{#titleparts:</nowiki> {{ns:1}}:Foo/<span style="color: blue;">bar/baz/quok</span> <nowiki>| | 2 }}</nowiki></code> → '''{{#titleparts: {{ns:1}}:Foo/bar/baz/quok | | 2 }}'''
: <code><nowiki>{{#titleparts:</nowiki> {{ns:1}}:Foo/bar/baz/quok <nowiki>| | 5 }}</nowiki></code> → '''{{#titleparts: {{ns:1}}:Foo/bar/baz/quok | | 5 }} '''

两个值都接受负值。要返回的分段数量参数的负值会从字符串的最后开始“分解”分段。要返回的第一个分段参数的负值解释为“从这一分段开始，从右边开始计数”：

: <code><nowiki>{{#titleparts:</nowiki> <span style="color: blue;">{{ns:1}}:Foo/bar/baz</span>/quok <nowiki>| -1 }}</nowiki></code> → '''{{#titleparts: {{ns:1}}:Foo/bar/baz/quok | -1 }}''' <small>Strips one segment from the end of the string. See also [[Help:魔术字#Page_names|BASEPAGENAME]].</small>
: <code><nowiki>{{#titleparts:</nowiki> {{ns:1}}:Foo/bar/baz/quok <nowiki>| -4 }}</nowiki></code> → '''{{#titleparts: {{ns:1}}:Foo/bar/baz/quok | -4 }} ''' <small>Strips all 4 segments from the end of the string</small>
: <code><nowiki>{{#titleparts:</nowiki> {{ns:1}}:Foo/bar/baz/quok <nowiki>| -5 }}</nowiki></code> → '''{{#titleparts: {{ns:1}}:Foo/bar/baz/quok | -5 }} ''' <small>Strips 5 segments from the end of the string (more than exist)</small>
: <code><nowiki>{{#titleparts:</nowiki> {{ns:1}}:Foo/bar/baz/<span style="color: blue;">quok</span> <nowiki>| | -1 }}</nowiki></code> → ''' {{#titleparts: {{ns:1}}:Foo/bar/baz/quok | | -1 }}''' <small>Returns last segment. See also [[Help:魔术字#Page_names|SUBPAGENAME]].</small>
: <code><nowiki>{{#titleparts:</nowiki> {{ns:1}}:Foo/<span style="color: blue;">bar/baz</span>/quok <nowiki>| -1 | 2 }}</nowiki></code> → ''' {{#titleparts: {{ns:1}}:Foo/bar/baz/quok | -1 | 2 }}''' <small>Strips one segment from the end of the string, then returns the second segment and beyond</small>
: <code><nowiki>{{#titleparts:</nowiki> {{ns:1}}:Foo/bar/<span style="color: blue;">baz</span>/quok <nowiki>| -1 | -2 }}</nowiki></code> → ''' {{#titleparts: {{ns:1}}:Foo/bar/baz/quok | -1 | -2 }}''' <small> Start copying at the second last element; strip one segment from the end of the string</small>

处理前，页面名称参数是HTML解码的：如果包含一些标准的HTML字符实体，将被转换为纯字符（内部使用UTF-8编码，也就是与使用解析器函数的MediaWiki源页面中的编码相同）。
:例如，页面名称中出现了<code>&amp;quot;</code>、<code>&amp;#34;</code>、<code>&amp;#x22;</code>的地方，都会替换为<code>"</code>
:不会执行从HTML到纯文本的其他转换，因此即使HTML标签在页面标题中无效，在此初始步骤中也会保持不变。

MediaWiki的一些魔术字或解析器函数（例如<code><nowiki>{{</nowiki>PAGENAME<nowiki>}}</nowiki></code>和类似）会返回用多余的HTML编码的字符串，即使其自身的输入参数不是HTML编码的：

titleparts解析器函数可以用作一个解决办法，以转换返回的字符串，因此可以被其他的一些解析器函数正确处理，如果这些解析器函数参数中也会接收页面名称，比如<code><nowiki>{{</nowiki>PAGESINCAT:<nowiki>}}</nowiki></code>（但对于HTML编码的字符串仍然不能正确处理）。

例如，如果当前页面是[[commons:Category:Côte-d'Or|Category:Côte-d'Or]]，那么：
* <code><nowiki>{{#ifeq: {{FULLPAGENAME}} | Category:Côte-d'Or | 1 | 0 }}</nowiki></code> and <code><nowiki>{{#ifeq: {{FULLPAGENAME}} | Category:Côte-d&amp;apos;Or | 1 | 0 }}</nowiki></code> are both returning <tvar|actual><code>1</code>; (the #ifeq parser function does perform the HTML-decoding of its input parameters).
* <code><nowiki>{{#switch: {{FULLPAGENAME}} | Category:Côte-d'Or = 1 | #default = 0 }}</nowiki></code>, and <code><nowiki>{{#switch: {{FULLPAGENAME}} | Category:Côte-d&amp;apos;Or = 1 | #default = 0 }}</nowiki></code> are both returning <code>1</code>; (the #switch parser function does perform the HTML-decoding of its input parameters).
* <code><nowiki>{{#ifexist: {{FULLPAGENAME}} | 1 | 0 }}</nowiki></code>, <code><nowiki>{{#ifexist: Category:Côte-d'Or | 1 | 0 }}</nowiki></code> or even <code><nowiki>{{#ifexist: Category:Côte-d&amp;apos;Or | 1 | 0 }}</nowiki></code> will all return <code>1</code> if that category page exists (the #ifexist parser function does perform the HTML-decoding of its input parameters);
*<code><nowiki>{{PAGESINCAT: Côte-d'Or }}</nowiki></code> will return a non-zero number, if that category contains pages or subcategories, '''but''':
* <code><nowiki>{{PAGESINCAT: {{CURRENTPAGENAME}} }}</nowiki></code>, may still '''unconditionally''' return 0, just like:
* <code><nowiki>{{PAGESINCAT: {{PAGENAME|Category:Côte-d'Or}} }}</nowiki></code>
* <code><nowiki>{{PAGESINCAT: {{PAGENAME|Category:Côte-d&amp;apos;Or}} }}</nowiki></code>

这种非预料行为的原因是，对于当前版本的MediaWiki，有两个警告（caveats）：

*<code><nowiki>{{FULLPAGENAME}}</nowiki></code>, or even <tvar|code1><code><nowiki>{{FULLPAGENAME|Côte-d'Or}}</nowiki></code> ''may'' return the actually HTML-encoded string <tvar|actual><code>Category:Côte-d&amp;apos;Or</code> and not the expected <tvar|expected><code>Category:Côte-d'Or</code>, and that:
*<code><nowiki>{{PAGESINCAT: Côte-d&amp;apos;Or }}</nowiki></code> '''unconditionally''' returns 0 (the PAGESINCAT magic keyword does not perform any HTML-decoding of its input parameter).

使用titleparts的简单解决方法（如果上述两个警告在MediaWiki的更高版本中修复了，也会继续生效）：

* <code><nowiki>{{PAGESINCAT: {{titleparts: {{CURRENTPAGENAME}} }} }}</nowiki></code>
* <code><nowiki>{{PAGESINCAT: {{titleparts: {{PAGENAME|Category:Côte-d'Or}} }} }}</nowiki></code>
* <code><nowiki>{{PAGESINCAT: {{titleparts: {{PAGENAME|Category:Côte-d&amp;apos;Or}} }} }}</nowiki></code>, that all return the actual number of pages in the same category.

解码后的''页面名称''会尽可能标准化为MediaWiki支持的标准页面名称：

#所有下划线都自动替换为空格：
#: <code><nowiki>{{#titleparts:</nowiki> {{ns:1}}:Foo/bah_boo|1|2}}</code>  → '''{{#titleparts: {{ns:1}}:Foo/bah_boo|1|2}}''' <small><!--T:2372--> Not bah_boo, despite the underscore in the original.</small>
#  字符串最多分割25次；更多的斜杠都会忽略，第25个元素将会包含字符串的剩余内容。 字符串也限制在255个字符内，因为要被视为页面标题：
#: <code style="white-space: pre-wrap"><nowiki>{{#titleparts: </nowiki>a / b / c / d / e / f / g / h / i / j / k / l / m / n / o / p / q / r / s / t / u / v / w / x / <span style="color: blue;">y / z / aa / bb / cc / dd/ ee</span> <nowiki>| 1 | 25 }}</nowiki></code> → '''{{#titleparts: a/b/c/d/e/f/g/h/i/j/k/l/m/n/o/p/q/r/s/t/u/v/w/x/y/z/aa/bb/cc/dd/ee | 1 | 25 }}'''
#: 如果出于某些原因确实要将此函数推到极限（尽管不太可能），可以通过嵌套函数调用来绕过只能分割25次的限制：
#: <code><nowiki>{{#titleparts: {{#titleparts: </nowiki>a / b / c / d / e / f / g / h / i / j / k / l / m / n / o / p / q / r / s / t / u / v / w / x / y / <span style="color: blue;">z</span> / aa / bb / cc / dd / ee<nowiki>| 1 | 25 }} | 1 | 2}}</nowiki></code> → '''{{#titleparts: {{#titleparts: a/b/c/d/e/f/g/h/i/j/k/l/m/n/o/p/q/r/s/t/u/v/w/x/y/z/aa/bb/cc/dd/ee | 1 | 25 }} | 1 | 2}}'''
# The list of substrings is not cleaned up hierarchically (unlike with the <code><nowiki>{{</nowiki>{{ll|Help:Magic words#Page names|PAGENAME}}<nowiki>}}</nowiki></code> magic keyword, the <tvar|code1><code>./</code> and <code>../</code> relative path segments are left intact by #titleparts):
#: <code><nowiki>{{#titleparts:</nowiki> ../c/d <nowiki>}}</nowiki></code> → '''{{#titleparts: ../c/d }}'''
#: <code><nowiki>{{PAGENAME:</nowiki> ../c/d <nowiki>}}</nowiki></code> → '''{{PAGENAME: ../c/d }}'''
# 最后，第一个子字符串根据本地wiki的大小写设置进行大写（如果该子字符串也以本地命名空间名称开头，则该命名空间名称也被标准化）。
#: <code><nowiki>{{#titleparts:</nowiki> <span style="color: blue;">talk:a</span>/b/c <nowiki>}}</nowiki></code> → '''{{#titleparts: talk:a/b/c }}'''

您可以把#titleparts用作一个小的“字符串解析器和转换器”，但要考虑到返回第一个子字符串会大写：

: <code><nowiki>{{#titleparts:</nowiki> <span style="color: blue;">one</span>/two/three/four<nowiki>|1|1 }}</nowiki></code> → '''{{#titleparts: one/two/three/four|1|1 }}'''
: <code><nowiki>{{#titleparts:</nowiki> one/<span style="color: blue;">two</span>/three/four<nowiki>|1|2 }}</nowiki></code> → '''{{#titleparts: one/two/three/four|1|2 }}'''

如果需要小写，使用lc:函数以控制输出：

: <code><nowiki>{{lc: {{#titleparts:</nowiki> <span style="color: blue;">one</span>/two/three/four<nowiki>|1|1 }} }}</nowiki></code> → '''{{lc: {{#titleparts:one/two/three/four|1|1 }}}}'''
你可以在字符串开头添加一个“伪”斜杠以修正第一个子字符串的大小写。对于要返回的第一个分段，应使用<code>2</code>而不是<code>1</code>。

: <code><nowiki>{{#titleparts:</nowiki> '''/'''<span style="color: blue;">one</span>/two/three/four<nowiki>|1|</nowiki>'''<u>2</u>'''<nowiki> }}</nowiki></code> → '''{{#titleparts: /one/two/three/four|1|2 }}'''
: <code><nowiki>{{#titleparts:</nowiki> '''/'''<span style="color: blue;">One</span>/two/three/four<nowiki>|1|</nowiki>'''<u>2</u>'''<nowiki> }}</nowiki></code> → '''{{#titleparts: /One/two/three/four|1|2 }}'''

一些字符在页面标题中是非法的，会导致#titleparts不去解析字符串。

: <code><nowiki>{{#titleparts: {one/two} | 1 | 1 }}</nowiki></code> → '''{{#titleparts: {one/two} | 1 | 1 }}'''. <small>Does not produce the expected:'''{one'''</small>
: <code><nowiki>{{#titleparts: [[page]]/123 | 1 | 2 }}</nowiki></code> → '''{{#titleparts: [[page]]/123 | 1 | 2 }}'''. <small> 不起作用，因为页面标题中的中括号是非法的，并且此解析器函数不处理嵌入在其输入的“页面名称”参数中的链接，即使使用了MediaWiki语法或任何其他HTML或MediaWiki标签。</small>
: <code><nowiki>{{#titleparts: red/#00FF00/blue | 1 | 3 }}</nowiki></code> → "{{#titleparts:  red/#00FF00/blue| 1 | 3 }}". <small> 不起作用，因为“#”在页面标题中是非法的。</small>

如果输入超过255个UTF-8字节，则此函数不会正常降级（degrade gracefully）。如果输入字符串为256字节或更多，则返回整个字符串。

* <code><nowiki>{{#var_final:</nowiki>''变量名称''|默认值}}</code>
''默认值''可以作为页面变量的“兜底”，即确保了即使没有任何赋值的情况下也能使得该变量有一个默认值。

===arraymap===
arraymap是一个灵活的函数，用以展开一段内容中的每一个元素，具体方法：
*<code><nowiki>{{#arraymap:<要展开的内容>|<分隔符>|<变量>|<变量公式>|<展开后的分隔符>}}</nowiki></code>
如果要展开的内容是一个逗号隔开的字符串，例如：<code>关羽,张飞,马超,赵云,黄忠</code>
*<code><nowiki>{{#arraymap:关羽,张飞,马超,赵云,黄忠|,|@@@|{{CharacterInfo|@@@}}|<br>}}</nowiki></code>
这段代码的意思就是将关羽、张飞、马超、赵云、黄忠视为要展开的5个元素（由指定的分隔符“,”从要展开的字符串里获得），每个元素都被放到公式“<nowiki>{{CharacterInfo|@@@}}</nowiki>”中去并用换行符隔开，代码展开为html之前等价于：
*<code><nowiki>{{CharacterInfo|关羽}}<br>{{CharacterInfo|张飞}}<br>{{CharacterInfo|马超}}<br>{{CharacterInfo|赵云}}<br>{{CharacterInfo|黄忠}}</nowiki></code>


利用arraymap我们可以模拟打印表格，公式生成每一行，在整段代码前放上th和table标签，整段代码之后用table标签闭合即可

===default form===
<code>default form</code>函数用来为当前页面制定默认使用的表单，指定后页面就可以使用表单编辑。

===arraydefine===
'''语法:'''
<code><nowiki>{{#arraydefine:数组名|赋值来源|分隔符|选项参数}}</nowiki></code>
{| class="wikitable"
|-
!参数
!描述
|-
|使用正则表达式作为分隔符，例如<nowiki>/\s*[;,]\s*/</nowiki>
|<code><nowiki>{{#arraydefine:f|apple, pear;  orange|/\s*[;,]\s*/}}</nowiki></code>
|-
|选项参数：<code>unique</code>，将赋值自动去重
|<code><nowiki>{{#arraydefine:b|orange,red ,yellow, yellow|,|unique}}</nowiki></code>中，两个yellow只会被保留1个
|-
|选项参数：<code>sort=</code>，可选值
*<code>none (default)</code> - 不予排序
*<code>desc</code> - 降序
*<code>asce/asc</code> - 升序
*<code>random</code> - 随机，乱序
*<code>reverse</code> - 反序
|<code><nowiki>{{#arraydefine:b|orange,red ,yellow, yellow|,|unique,sort=desc}}</nowiki></code>
|-
|选项参数：<code>print=</code>，可选值，将内容打印出来
*<code>list</code> - 不予排序
|<code><nowiki>{{#arraydefine:b|orange,red ,yellow, yellow|,|unique,sort=desc,print=list}}</nowiki></code>
|}
===arrayprint===
'''语法:'''
<code><nowiki>{{#arrayprint:数组名|分隔符|定义格式|表达式|选项参数}}</nowiki></code>
该函数功能类似arraymap，将制定数组按照所制定的分隔符分割，并将每一元素按照表达式展开。一般和arraydefine成对使用。

===arrayindex===
'''语法:'''
<code><nowiki>{{#arrayindex:数组名|元素序号|返回默认值}}</nowiki></code>
{| class="wikitable"
|-
!参数
!描述
|-
|元素序号，基数为<code>0</code>（第一个元素），如果序号超出范围或者无效，arrayindex函数会返回空值。负数序号表示反序取值（从最后开始取），<code>-1</code>表示数组的最后一个元素。
|<code><nowiki>{{#arrayindex:a|0}}</nowiki></code><code><nowiki>{{#arrayindex:b|-1}}</nowiki></code>
|-
|返回默认值，当查询不到对应元素时返回的默认结果
|<code><nowiki>{{#arrayindex:c |foo |数值不存在！ }}</nowiki></code>
|}
