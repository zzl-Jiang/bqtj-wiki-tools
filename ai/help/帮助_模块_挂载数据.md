本文档介绍如何在灰机wiki的lua模块中导入本站网页上的数据，其目的是将——
*json数据导入为luaTable
*luaTable导入为luaTable


==关于mw.loadData()==
这是一个mw内置的标准方法，其用法为
<pre>
local data = mw.loadData('yourPage')
</pre>

;例子
<pre>
local data = mw.loadData('module:Test/Data')
</pre>

其优点是无论一个页面调用多少次，这部分数据只加载一会，是非常有效的规避高开销超限手段。


==方法一，挂载静态luaTable==
在目标'module:Test/Data'里生成一个静态的luaTable，一般作为枚举，比如
<pre>
local p ={
   a = 'a',
   b = 'b'
}
return p
</pre>

==方法二，挂载动态luaTable==
也就是说在目标'module:Test/Data'里return的最终结果p（luaTable）是动态构建的，

最常见的方法是通过灰机提供的mongoDB数据库和lua函数来动态查询特定的数据（技能、物品等等）

书写语法参考：[[帮助:模块/MongoDB函数]]，此处不再赘述。

<pre>
local p ={}

function p._query(frame)

  local res = mw.huiji.db.find('...')
  return res
  
end

return p
</pre>

==方法三，挂载静态JSON==
目标路径指向的是一个content model为JSON的页面，在灰机wiki，常见的包括：
*Data:XXXX.json(使用mongoDB的json页面)
*Data:XXXX.tab/tabx(使用mongoDB的json页面形态二)
*Data:XXXX(不使用mongoDB的data页面，需要确认其内容是合法JSON)
*MediaWiki:Huiji-translation-pairs(译名表，参考[[帮助:模块/使用译名表]])

需要注意，目标路径内容在load之后需要做json的解码，函数如下：
<pre>
function p.load_json(page_title)
    return mw.text.jsonDecode(mw.title.new(page_title):getContent())
end
</pre>

对于<code>Data:XXXX.json</code>也可以使用[[帮助:模块/灰机特有函数#loadJson|mw.huiji.loadJson]]函数
