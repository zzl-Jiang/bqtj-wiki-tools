'''灰机 Agent'''是灰机提供的维基 AI 助手。它根据你的提问调用工具查询、整理，然后给出答复；其中工作区 Agent 可以直接编辑站点上的页面。

目前仅对完成手机实名认证的用户开放。

==原理==

以提问「R6S 里 Maverick 的主武器是什么」为例，一次问答的过程如下：

<pre lang="mermaid" >
sequenceDiagram
    autonumber
    participant U as 用户（浏览器）
    participant S as 灰机服务端
    participant M as 大模型
    participant T as 工具

    U->>S: 发送问题
    S->>M: 会话历史 + 可用工具清单
    M->>S: 调用「搜索本站知识库」
    S->>T: 执行工具
    T-->>S: 命中的页面/章节正文
    S->>M: 工具结果
    M->>S: 调用「读某一章节」
    S->>T: 执行工具
    T-->>S: 该章节正文
    M-->>S: 整理答案并附引用
    S-->>U: 返回回答
</pre>

==通用 Agent==

入口：[[club:special:cockpit#/agentv2/chat|灰机 Agent]]。

通用 Agent 不限定站点，哪个站点的问题都能问。它的工具最多：知识库、维基实时页面、站点检索、文档中心、联网搜索均可调用。

适合查「某个内容在灰机的哪个站、哪一页」，或者「对照几个站的说法」。

检索时优先走知识库，查不到再改用维基搜索和维基实时页面。实时页面消耗燃料较多，建议站点尽早把已完成的内容收录进[[帮助:知识库|知识库]]。

==站点 Agent==

站点 Agent 也就是'''站点助手'''，由站点管理员配置，主要面向站点的读者。

站点管理员需要先到[[club:special:cockpit#/kb/@home|知识库项目页]]开启该功能。之后可以通过以下入口打开对话窗口：
*站点任意页面，右侧边栏的站点助手按钮
*主导航，HuijiAgent → 站点助手
*驾驶室：进入当前站点主页（主导航 → 驾驶室 → 驾驶室:当前站点），第一个卡片

也可以通过 JS 执行 <code>window.$siteAgent.show()</code> 打开站点助手。

站点管理员可以为站点助手配置头像、名字、性格和回答风格。

===知识库===
站点助手直接读取知识库。把站点的有效内容收录进去，响应更快，也更省燃料，具体见[[帮助:知识库|帮助:知识库]]。

==工作区 Agent==

入口：[[club:special:cockpit#/workspace/@home|工作区]]右侧的助手。

*它读取的是编辑器当前状态：打开了哪些页面、光标在哪、编辑器缓冲区里的正文。这类信息服务端看不到，所以相关工具在浏览器里执行。
*适合「把这五页的分类统一一下」「照这个模板批量改一遍」这类工作。
*它不负责保存。改动后需要手动点「全部保存」。

具体用法见[[帮助:工作区]]。

==燃料==

使用灰机 Agent 会消耗燃料，查得越多、思考越复杂，消耗越大。部分工具调用会额外计费，见下文「Agent 工具」。

===怎么获得===

在[[club:special:cockpit#/fuel/home|加油中心]]加油（捐赠）可获得燃料，每 1 元人民币兑换 1000 燃料。
*实名加油，燃料全部计入你的账户。
*匿名加油，燃料进入对应站点的燃料池。

[[club:special:cockpit#/fuel/fuellog|燃料日志]]里可以查看余额、充值记录和消耗明细。

===燃料的消耗===

*'''提问'''：消耗与你提问的长度、当次会话的历史长度相关。
*'''回答'''：消耗与回答长度相关；开启思考模式时，思考过程也会消耗一部分。
*'''工具调用'''：消耗与请求长度、工具返回内容的长度相关。部分工具走外部服务，每次额外扣除固定燃料。

节约燃料的几点建议：
*换话题时新开会话，历史记录太长会持续增加消耗。话题不变则继续用当前会话更便宜（燃料日志中显示为 cacheHit）。
*站点 Agent 尽量把知识库建全，直接查维基比查知识库贵很多。
*非高峰时段（工作日 9:00–12:00、14:00–18:00 以外）最低五折。

===欠费与透支===

灰机用户等级 2（约 1200 经验）的用户有 1000 的透支额度，燃料余额降到 -1000 以下才会阻止继续对话。其余用户余额须大于 0。

===站点燃料池===

暂未开放。

==Agent 工具==

灰机 Agent 的工具分六类：

*知识库工具（kb）
**检索站点已收录进知识库的内容
*维基实时页面（wiki）
**在维基内搜索、获取页面全文和信息
**比知识库消耗高，但不受知识库采集范围和采集周期限制
*站点与文档
**判断该去哪个站点找资料
**检索灰机维护的站外知识库，主要是 JS、CSS、HTML 资料，来源为 MDN
*联网搜索
**搜索灰机体系之外的信息，有固定的燃料费用
*前端操作
**主要用于工作区 Agent：把页面加入工作区、在工作区内编辑等
*杂项
**算术、文本转码、JSON 校验、读取服务器时间、会话重命名等

===工具调用与知识库===

知识库里的内容经过'''预先清洗并分段'''。以 R6S 的[[r6s:Maverick|Maverick]]为例，该页原始数据 133 KB，转成 Markdown 后只剩 13 KB。

如果页面没有进知识库，Agent 只能用维基搜索取整页分析，取到的大部分是 HTML 标签、布局和空白；页面过长还会被截断。回答同一个问题，燃料消耗至少涨十倍，准确性也没有保证。

怎么建库、怎么划定采集范围，见[[帮助:知识库|帮助:知识库]]。

===自定义工具===

站点自定义工具接口尚未开放，开放后站点可以通过两种方式提供查询函数：
*前端：封装成 JS 函数。
*后端：通过 Lua API 提供查询接口。
