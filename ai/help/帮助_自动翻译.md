'''自动翻译'''是灰机Wiki提供的批量翻译对照解决方案。集成在'''源代码编辑器'''中的一项辅助功能。自动翻译目前已实现一对一配对翻译。

自2026年10月起，自动翻译数据的维护功能迁移至Cockpit站点页。旧版译名表仍保留，但自动翻译功能将不再使用旧版译名表。

==译名表从哪里来==
===途径一：自动采集===
当你在页面中包含[[Help:跨语言链接|跨语言链接]]时（或使用会生成跨语言链接的模板时），该链接的内容和当前页的名称将自动在服务器中形成对应关系。但目前自动翻译功能仅会使用en语言的条目。

===途径二：手动提交===
站点管理员可以通过<code><nowiki>https://club.huijiwiki.com/wiki/special:cockpit#/site/<你的站点前缀>/translation</nowiki></code>页进行译名表维护。

===途径三：从旧版译名表迁移===
在途径2的页面中有一个“导入”按钮。该按钮会从你站点的<code>MediaWiki:Huiji-translation-pairs</code>中获取数据并写入新译名表。多次导入将视为追加（会自动排重）。

由于旧译名表是一个维基页面、且具有2MB的内容上限，我们建议后续均在新译名表中进行维护。

新译名表暂时没有版本记录，请务必注意数据安全。

==自动翻译怎么使用==
'''只有内容模型为wikitext的页面'''能使用自动翻译。

编辑页面时，主编辑区上方会生成一个“用译名表翻译”按钮。如果该站点的译名表存在且不为空，则按钮将亮起，点击后会进入翻译界面。

在该界面点击右上角的“用译名表翻译”即可进行自动翻译。在翻译完成后，你还可以手动对页面进行更改。

点击右下角的“接受”按钮后，翻译成果会同步到页面原有的编辑框，再次点击提交即可保存。

==自动翻译规则==
译名表分为如下几个类型：
*链接，对应旧译名表的link字段；
*纯替换，对应旧译名表的plain字段；
*正则，对应旧译名表的regex字段。

===内链的翻译===
脚本会首先提取所有的内链（双中括号），然后按如下顺序处理：
#首先按译名表的“链接”进行替换；
#然后按照跨语言链接生成的译名进行替换。

如果链接本身是蓝链，则替换时会将翻译内容写入内链的文本（而不是链接本身）。

===正则翻译===
如题。你在正则表中的第一段即为表达式（请注意转义符号），第二段为替换文本。
<pre>
{"/[abc]+/":"一二三"}
</pre>

===纯替换===
如题。

==旧版功能==

以下功能均只适用于旧版译名表（Mediawiki:Huiji-translation-pairs）。

===Mediawiki:Huiji-translation-pairs===
旧版译名表页面。格式为：
<syntaxhighlight lang=json>
{
    "version": 2,
    "plain": {
        "plain text": "文本"
    },
    "regex": {
        "/regular expression/i": "正则"
    },
    "link": {
        "link": "链接",
        "category:my category": "分类:我的分类"
    }
}
</syntaxhighlight>

===在模块（lua）内使用译名表===
预封装模块：参见[[Templatemanager:Module:Trans]]。

或者也可以自己实现：
<pre>
    local title = mw.message.new( 'Huiji-translation-pairs')
    local string = title:plain()
    local json = mw.text.jsonDecode(string)
</pre>
<pre>
    local title = mw.title.makeTitle( 'MediaWiki', 'Huiji-translation-pairs')
    local string = title:getContent()
    local json = mw.text.jsonDecode(string)
</pre>

===使用解析器函数===
有两种方式：
* <nowiki>{{#Trans:XXX|strict/lloose}}</nowiki>
* <nowiki><trans mode="strict/loose">YYY</trans></nowiki>
两者都有一个mode参数。如果mode=loose，则将调用有道翻译。反之则仅从Huiji-translation-pairs和跨语言链接中读取信息。默认为loose。
