'''用户'''是指灰机wiki上的注册用户。<br/>
注册用户可能是'''人类用户'''，也可能是'''机器人'''。<br/>
灰机wiki通过验证电子邮箱来限制未经验证用户的编辑等操作，但这不属于MediaWiki禁止的范畴。
== 注册用户权限 ==
*sendGifts <code>(sendGifts)</code>——发送“礼物”
*skipcaptcha <code>(skipcaptcha)</code>——跳过验证码
*上传文件 <code>(upload)</code>
*从URL上传文件 <code>(upload_by_url)</code>
*使用写入API <code>(writeapi)</code>
*创建讨论页面 <code>(createtalk)</code>
*创建非讨论页面 <code>(createpage)</code>
*发送电子邮件给其他用户 <code>(sendemail)</code>
*在个别修订和日志记录中添加和移除任意标签 <code>(changetags)</code>
*将Flow话题标记为已解决 <code>(flow-lock)</code>
*提交吐槽 <code>(comment)</code>
*无确认清除页面缓存 <code>(purge)</code>
*标记编辑为小编辑 <code>(minoredit)</code>
*移动分类页面 <code>(move-categorypages)</code>
*移动文件 <code>(movefile)</code>
*移动根用户页面 <code>(move-rootuserpages)</code>
*移动页面 <code>(move)</code>
*移动页面及其子页面 <code>(move-subpages)</code>
*绕过对tor出口节点的自动封禁 <code>(torunblocked)</code>
*编辑页面 <code>(edit)</code>
*连同某人的更改一起应用标签 <code>(applychangetags)</code>——将标签应用于修改
*阅读页面 <code>(read)</code>
== 未登录用户权限 ==
MediaWiki始终关注ip用户的人权问题，虽然灰机wiki并不在意这些。为了表示尊重，MediaWiki将以下权限赋予未登录用户。
*使用写入API <code>(writeapi)</code>
*创建讨论页面 <code>(createtalk)</code>
*创建账户 <code>(createaccount)</code>
*创建非讨论页面 <code>(createpage)</code>
*查看您的监视列表 <code>(viewmywatchlist)</code>
*查看您的私人数据（如电子邮件地址、真实姓名） <code>(viewmyprivateinfo)</code>
*编辑您的个人设置 <code>(editmyoptions)</code>
*编辑您的用户CSS文件 <code>(editmyusercss)</code>
*编辑您的用户JavaScript文件 <code>(editmyuserjs)</code>
*编辑您的监视列表。请留意即使缺少此权限，某些操作仍将添加页面至监视列表。 <code>(editmywatchlist)</code>
*编辑您的私人数据（如电子邮件地址、真实姓名） <code>(editmyprivateinfo)</code>
*阅读页面 <code>(read)</code>
*隐藏Flow话题和帖子 <code>(flow-hide)</code>
== 结尾 ==
如果您对用户方便还有什么疑问，欢迎您到[[帮助讨论:用户手册]]提出一个新话题。
