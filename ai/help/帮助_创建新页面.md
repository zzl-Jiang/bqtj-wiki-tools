== 创建前的准备 ==
*'''检查页面是否存在'''：写之前先搜索，避免内容已经存在。
* '''如果相似、相关条目已经存在'''：应先阅读、了解条目的内容，思考一下是否真的需要新建一个页面。又或许您只需要创建一个'''[[help:重定向页面|重定向页面]]'''即可解决问题。您也可以考虑扩充现有的条目，这样更有助拓展条目主题的广度和深度。
* '''如果尚未收录合适的条目'''：就可以开始'''创建页面'''了！

== 创建页面 ==
*'''方法一'''：在灰机侧边栏的“创建页面”框中输入你想建立的页面名称，点击“创建页面”，如果页面存在，会直接进入编辑模式
*'''方法二'''：在地址栏中直接输入，维基的页面地址是严格遵照<pre>“<子站前缀>.huiji.wiki/wiki/<页面名称>”</pre>的方式组成的，因此您只需要将当前页面的名称替换成想要寻找的页面名称即可，例如<code>lotr.huiji.wiki/wiki/Modor</code>。如果是模板、模块等带有前缀的页面，则需要加上“<code>模板:”\“模块:”\“帮助:”\“特殊</code>:”……等namespace前缀，如"<code>分类:人物</code>" 、"<code>模板:infobox</code>" 前缀缺省则生成默认文章页。
**模板、模块、帮助、分类、特殊等namespace前缀可以用“Template”、“Module”、“Help”、“Category”、“Special”来替代；
**无论是使用中文还是英文的namespace前缀，冒号必须是英文的半角冒号

*关于何为命名空间，请参阅'''[[Help:命名空间|命名空间]]'''
* 关于如何使用维基编辑功能，参见'''[[h:帮助:编辑页面|如何编辑页面]]'''。
* 关于如何撰写一篇维基条目，参见[[#注意事项|下文]]以及'''[[h:帮助:维基条目编写指南|快速指南]]'''。
* 完成输入条目内容后，欢迎使用预览功能查阅效果。

== 注意事项 ==

您所创建的条目必须合乎'''[[project:使用条款和内容声明|灰机wiki的使用条款]]'''，'''[[project:用户编辑条款|灰机wiki用户编辑条款]]'''以及子站点的相关规范。否则，条目将很可能被删除。
* '''请勿提交任何受版权保护的文章'''：灰机wiki和维基百科一样，是自由开放的百科全书，任何提交的文章都会在[[创作共享]]署名-相同方式共享 3.0未本地化的条款下自由发布与使用。参见[[帮助:版权信息(CC BY-SA) ]]。
* 请提前确认您要提交的内容[[灰机wiki:使用条款和内容声明#用户行为|是否适合收录在灰机wiki]]。
* 仔细阅读[[h:命名常规|条目命名常规]]：这对于创建新条目非常重要。
* 注意新条目与现存其他条目之间的关系，适当利用各种[[h:Help:链接|链接]]，让新条目与整个百科形成"“网络”"关系，而不是“孤立条目”。要了解您的条目是否孤立，可参照“[[特殊:孤立页面]]”内的相关信息。

== 编辑技巧 ==

在创建新条目之前，建议阁下：
* 了解维基代码与符号：如何[[h:Help:编辑页面|编辑页面]]
* 先试着编辑现有的文章，以获得编写和使用[[h:帮助:编辑页面|维基标记语言(Wikitext)]]的经验。另外，尝试阅读和参考一些被公认为优质的条目，参见[[h:Help:维基化|维基化]]。
* 阅读[[h:Help:FAQ|常见问题解答]]和社区相关内容从中获得有益的建议与指导。
