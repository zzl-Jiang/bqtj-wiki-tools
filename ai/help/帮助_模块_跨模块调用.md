我们可以将通用的function单独存放在一个模块中，方便调用，从而缩减特定模块页面的代码篇幅，并实现模块化开发。与其他变成语言类似，在MediaWiki中，我们可以通过<code>require( modulename )</code>来实现代码块的'''引入'''。

==本地化声明外部函数==
下面语句可以将外部的function“本地化”。

<pre>
local _getImage =require('Module:GetData')._getImage
local _textTrim =require('Module:GetData')._textTrim
</pre>

===范例===

<code>模块:Foo</code>的代码：
<pre>
local p = {}
local Foo2 = require('Module:Foo2')

function p.test(frame)
  return Foo2.do(frame.args[1])
end

return p
</pre>

<code>模块:Foo2</code>的代码：
<pre>
local p = {}

function p.do(text)
  return '《'..text..'》'
end

return p
</pre>

此时使用下面的语句进行调用时：
<pre>
{{#invoke:Foo|test|灰机wiki}}
</pre>

调用结果为“《灰机wiki》”字样。
