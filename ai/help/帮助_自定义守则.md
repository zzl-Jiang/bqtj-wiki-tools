# 帮助:自定义守则

<div class='well'>
当用户从一个社区到另一个社区，从一开始的读者变成编辑者（直至站长），把从站点上学到的东西运用到建站上是十分重要的。这种学习经验的关键部分就是使用户界面和功能具备延续性。这并不等同于没有个性化定制和个体特色——这些对于灰机用户来说是十分重要的元素。但是游客们在灰机页面上浏览时，他们希望用户界面和基本功能应该出现在醒目的位置。
</div>

* 为了给你站点的浏览者进行个性化定制，我们推荐你使用[[Bootstrap:自定义主题|自定义主题]]。这能帮助你基于已选主题上自动挑选文本和区域颜色。

* 如果想达到更具特色的效果，我们也为每个社区提供了[[Help:修改站点CSS|一个CSS编辑页面]]。它既可以用来修改infobox模板和表格的样式、控制颜色，也可以为页面的几乎任何部分增加装饰（包括边框和字体变化）。但是请不要用它来改变任何文本框架结，以及删除、移动、转化广告或者灰机导航栏的格式，也不能用来改变灰机的特性和功能。

* 通过修改MediaWiki信息可以变更站点中的措辞。但是我们建议您尽量不要这么做，如果你给“编辑”键重命名为“二哈”，没人会知道那是什么意思。

* 我们鼓励有经验的用户在灰机预设值的基础上修改站点设置，而不是重新创造一套框架。

* 站长应为站点的安全性最终负责，请不要引用来源不明的代码。

* 为CSS的修改创建一个详尽的列表来约束“可行”和“不可行”是不切实际的，因为这其中有太多的可能性。但是下面我们会举例来告诉您哪些可以做、哪些不可以做：

{| class="wikitable table table-striped"
!针对广告、灰机logo、灰机导航栏及固有功能进行移除、修改位置或修改其功能
|这些是站点的基本框架，必须保留其原有位置。游客们应该时刻能在相同的位置看到灰机预设的功能键，而且这些按钮理应做到“字义即功能”。一些功能是可关闭的，但是我们希望您通过管理员选项来配置，而不是CSS来将它们隐藏掉。我们需要了解这些功能的实际运作情况，并且得到它们在使用中的一些准确数据。 
|-
!将站点内容下移，以添加额外的banner横幅或logo徽记
|请不要改变文章标题位置，也不要在标题上方添加任何元素。如果你想添加一个横幅，你可以在文章区域进行操作，文章内容也会相应下移。
|-
!页面宽度及侧边栏的更改
|页面宽度（包括最大和最小的宽度）和侧边栏是灰机wiki页面视觉效果的重要决定因素。
|-
!给按键、文本框、背景或文字增添装饰
|装饰和格式设置是凸显个性的绝佳方式，用主题设计器是最简单的实现方式，当然也可以通过修改CSS来完成。但是请不要改变灰机logo的颜色和样式。
|-
!按键用词和其他元素的改变
|通过修改MediaWiki信息可以改变站点的许多方面，包括一些功能的措辞表达。但我们不建议您这样做。因为一个统一的、不易混淆的界面才是最好的。但是某些时候，为了更加贴合具体社区气氛，您可以对措辞进行微调。
|-
!额外按键和链接的添加（JavaScript）
|灰机wiki的管理员有权限通过JavaScript对站点稍做调整，例如：在页面上添加外部链接。但是我们不建议您这样做，因为灰机wiki站点的全局变化可能会影响到你的代码。我们会尽力去规避这种情况，但如果您确实通过JavaScript对站点进行了修改，那么您应该意识到风险的存在。
|}
