==安装==
想要使用灰机推土机架构标准，建议安装一个零件<span class="btn btn-primary tf-batch" data-manifest="Manifest:灰机推土机标准">灰机推土机标准</span>，其中包含很多写好的辅助工具。

==实践==
灰机推土机架构采用一个统一的模板来封装所有数据。这个模板叫Data。所有的数据以命名参的形式传入模板中。让我们在Data命名空间下新建一个<code>哺乳动物</code>页面，并录入例子1中的内容。

===例子1===
<pre>
{{Data
|物种数量=5676
|胎生 = true
|出现时间=2亿多年前
}}
</pre>

效果可参阅：[[Shenzhen-io:Data:哺乳动物]]

请注意Data模板已经自动将数据可视化，并且生成了些辅助性的文档。请查看SMW属性，你会发现所有属性已经设置成功。

有时候我们需要为一个属性设置多个值，可以直接用英文半角逗号分离：

===例子2===
<pre>
{{Data
|物种数量=5676
|胎生 = true
|出现时间=2亿多年前
|具有亚纲=原兽亚纲,兽亚纲
}}
</pre>
Data模板会自动为您处理为一个属性对应多个值。当然，有时候我们必须要使用逗号，可以使用反斜线逗号(\,)进行转义。
===例子3===
<pre>
{{Data
|物种数量=5676
|胎生 = true
|出现时间=2亿多年前
|具有亚纲=原兽亚纲,兽亚纲
|具有出处=Clutton-Brock\, J. Dorling Kindersley Handbooks - Mammals.
}}
</pre>
显示出来的结果和属性会自动把反斜线去掉。
