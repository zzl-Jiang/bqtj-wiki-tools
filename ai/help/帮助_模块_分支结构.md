当需要程序根据条件判断接下来做什么的时候，就需要使用分支结构，Lua的分支结构，是使用<code>if</code>语句进行的。

该语句与解析器函数<code><nowiki>{{#if}}</nowiki></code>是一个原理，可以用替代该解析器函数。

==if语句==

<code>if</code>语句的基本使用方法是：
<pre>
if 条件 then
  -- 执行满足条件时的操作代码
end
</pre>

注意：条件后必须跟<code>then</code>，语句结束必须有<code>end</code>。

条件可以是任何值，通常会使用[[../运算符#关系运算符|关系运算符]]或[[../运算符#逻辑运算符|逻辑运算符]]进行计算获取条件是否成立（<code>true</code>或<code>false</code>）

注意：在Lua中，只有<code>false</code>和<code>nil</code>为假，<code>true</code>和其他所有值均为真，所以在Lua中，数字<code>0</code>也是<code>true</code>。

==if...else语句==

如果判断条件后，对不满足条件的项目也要进行特定处理的话，可以使用<code>if...else</code>语句：
<pre>
if 条件 then
  -- 执行满足条件时的操作代码
else
  -- 执行不满足条件时的操作代码
end
</pre>

==elseif语句==

当需要并列的数个条件，分别处理时，可以使用<code>elseif</code>语句

由于Lua没有switch语句，所以解析器函数<code><nowiki>{{#switch}}</nowiki></code>的功能，需要写成多个<code>elseif</code>语句

<pre>
if 第1个条件 then
  -- 执行满足第1个条件时的操作代码
elseif 第2个条件 then
  -- 执行满足第2个条件时的操作代码
elseif 第3个条件 then
  -- 执行满足第3个条件时的操作代码
else
  -- 执行上述三个条件都不满足时的操作代码
end
</pre>

==if嵌套==

Lua中也允许<code>if</code>语句进行嵌套，当需要递进式的判断时，则可以使用嵌套式的<code>if</code>语句：

<pre>
if 第一个条件 then
  if 第二个条件 then
  	-- 执行同时满足第1个条件和第2个条件时的操作代码
  elseif 第三条件 then
  	-- 执行同时满足第1个条件和第3个条件时的操作代码
  else
  	-- 执行满足第1个条件，但不满足第2个或第3个条件时的操作代码
  end
else
  -- 执行不满足第1个条件时的操作代码
end
</pre>
