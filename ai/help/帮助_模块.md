'''模块（Module）'''是一个MediaWiki的官方插件功能。该插件允许编写者在MediaWiki中，使用[https://www.lua.org/ Lua语言]来编写模块，完成一些批量工作的处理。'''模块'''可以理解为是一个“高级形态”的[[help:模板|模板]]。

== 什么是模块 ==
模块是Lua在MediaWiki执行的基础，Lua代码必须被写成若干个“模块”进行使用。

所有模块，需要建立在[[帮助:命名空间|命名空间]]<code>Module:</code>（<code>模块:</code>）下。

==为什么要使用模块==
{{quote|括海无边，回头是岸。|SerGawen}}
在复杂的模板中，我们通常会使用各种[[help:解析器函数|解析器函数]]来实现类似程序语言的逻辑判断和循环（比如<code><nowiki>{{#if}}</nowiki></code>）。

当一个模板比较简单，只会使用到少量解析器函数的时候，解析器函数是一个非常方便的功能。

但是，当一个模板需要做大量逻辑判断、循环之类功能的时候，就会导致模板的代码臃肿不堪，陷入由<code><nowiki>{{</nowiki></code>和<code><nowiki>}}</nowiki></code>组成的花括号地狱当中，这样的模板难以阅读和维护。

这种时候就更适合使用模块来进行编写。
#模块使用了真正的程序语言Lua，使其可以处理更复杂的逻辑判断;
#Lua代码的可读性更高，所以可以更轻松的制作出功能更丰富、也更利于维护的模板，也更有利于多人协奏。
#Lua的运行效率也比[[help:解析器函数|解析器函数]]更高，根据页面解析器函数的嵌套层次、复杂程度，改写成Lua可以显著提升页面的加载速度，解析器函数嵌套越多、调用次数越多、使用的SMW和Loop类函数越多，改写成Lua的效果就越明显。

==如何调用模块==

在MediaWiki中，可以使用'''[[help:解析器函数|解析器函数|]]'''<code><nowiki>{{#invoke}}</nowiki></code>（<code><nowiki>{{#调用}}</nowiki></code>）调用一个模块中的一个函数。

<pre>
{{#invoke:模块名|函数名|参数1|参数2...}}
</pre>

模块名指的是页面标题<code>Module:XXX</code>中的XXX。参数的写法和模板参数的写法是相同。

===tips===
下面是一些关于Lua的tip，方便有编程基础的开发者迅速了解Lua与其他语言，特别是JavaScript的区别
#Lua中所有的集合类型都是'''表'''（table），写作 <code>{ }</code>
#Lua中表的索引是从<code>'''1'''</code>开始，而不是<code>'''0'''</code>
#Lua中的变量必须先声明才可以使用
#Lua中的空值叫做<code>'''nil'''</code>而不是<code>'''null'''</code>
#Lua中没有<code>'''switch'''</code>函数，一般通过多次<code>'''elseif'''</code>或者建立一个<code>table</code>作为枚举来进行索引，以实现类似JavaScript或解析器函数中“switch”的效果。
#Lua中没有<code>'''replace'''</code>函数，但是可以用<code>'''[[帮助:模块/库与函数索引#mw.ustring.gsub|mw.ustring.gsub]]'''</code>或来替代。
#Lua中没有<code>'''split'''</code>函数，但是可以用<code>'''[[帮助:模块/库与函数索引#mw.text.split|mw.text.split]]'''</code>或来替代。
#Lua中的字符串连接符是<code>'''..'''</code>而不是JavaScript或者Python中的<code>'''+'''</code>。
#Lua中的“不等于”是<code>'''~='''</code>而不是JavaScript或者Python中的<code>'''!='''</code>。
#Lua中没有三元运算符<code>'''? :'''</code>，但可以通过<code>'''and'''</code>和<code>'''or'''</code>实现类似的效果
#Lua中的假值只有<code>'''nil'''</code>和<code>'''false'''</code>（<code>'''0'''</code>、<code>'''<nowiki>''</nowiki>'''</code>、<code>'''{}'''</code>在逻辑判断中都视为真）
#想要在<code>table</code>中删除一个值，只需将其设为<code>'''nil'''</code>
#<code>type</code>函数的返回值是一个字符串而不是保留字，比较时需要这么写<code>'''type(xxx) == "string/table/..."'''</code>

==常见问题==
<span class="text-danger">'''Lua错误：模块xxx第n行：attempt to index local ‘<some key>’(a nil value)'''</span>

'''可能的出错代码'''
<pre>
local id = data['id']
</pre>

'''原因'''：data为空值(nil)

'''解决方法'''：对data进行校验
<pre>
local id = 'default'
if data ~= nil and data['id'] ~= nil then
  id = data['id']
end
</pre>
上述代码可以简写为：
<pre>
local id = data and data['id'] or 'default'
</pre>
