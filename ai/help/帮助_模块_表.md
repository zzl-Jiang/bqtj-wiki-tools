表<code>table</code>是Lua中的一种[[../数据类型|数据类型]]，是一种功能非常丰富的数据类型。

==基本概念==

Lua的<code>table</code>是一种关联型的数组，每个值都有一个与之对应的索引，索引一般使用字符串（<code>string</code>）或是数值（<code>number</code>）。

<code>table</code>并不固定大小，随着添加的索引越来越多，会自动扩容。

在Lua中，<code>table</code>除了用来当做其他变成语言中的list（列表），dictionary（字典）或是array（数组）等数据类型外，还用来解决模块、包（package）和对象（object）这些功能的实现。

例如<code>string</code>库，实际上就是一个名叫string的table，而<code>string.find</code>函数，实际上是在这个table中，用find做索引对应到的那个函数。

<callout>需要注意的是，Lua的表从<code>'''1'''</code>开始索引，而不是<code>'''0'''</code></callout>

==基本使用==

以下为<code>table</code>的最基本使用方法：
<pre>
-- 通过给变量赋值 {} 来初始化一个table
-- 所有table使用前必须初始化
local test = {}

-- 通过[ ]选中一个索引进行赋值
test[1] = 'Hello'
test['name'] = 'Huiji'

-- 通过赋值 nil 删除一个索引对应的内容
test[1] = nil

-- 通过赋值 nil 删除table
test = nil
</pre>

==表的索引==
这里给定一个table
<pre>
local table = {
  ['name'] = 'hello',
  ['age'] = 18,
  ['job'] = 'unkonwn'
}
</pre>
那么:
*<code>table['name']</code>的值就是<code>'hello'</code>（key是‘name’的值）
*<code>table[1]</code>的值是<code>nil</code>（因为表中没有以[1]为索引的内容）

如果表中间有嵌套
<pre>
local table = {
  ['name'] = { ['first'] = 'hello', ['second'] = 'world' },
  ['age'] = 18,
  ['job'] = 'unkonwn'
}
</pre>
那么:
*<code>table['name']['first']</code>的值是<code>'hello'</code>
