==expose==
本函数可以将变量暴露到页面给JavaScript读取

例如，现在有以下Lua代码
<pre lang="lua">
mw.huiji.expose('Abc', { a = '...', b = '...' })
</pre>

在执行过该Lua代码的页面中，JavaScript可以通过以下方法获取到该对象
<pre>
mw.config.get('wgHuijiVars.Abc')
</pre>

需要注意的是，纯数字索引的Lua table，在暴露给JavaScript时，会变成一个数字索引的Object而不是一个Array，需要自己转换一遍，可以通过如下代码进行转换
<div class="darken mw-collapsible mw-collapsed">
JavaScript：可转换单个table的简易版
<div class="mw-collapsible-content"><pre>
function luaTableToArray(table) {
    var key_list = Object.keys(table);
    key_list.sort(function(a, b){
        return parseInt(a) - parseInt(b);
    })
    var result = [];
    for (const key of key_list) {
        result.push(table[key]);
    }
    return result;
}
</pre></div>

function luaTableToArray(table: Record<string, unknown>) {

<div class="darken mw-collapsible mw-collapsed">
JavaScript：递归转换全部table的版本
<div class="mw-collapsible-content"><pre>
function convertLuaTable(table) {
    var key_list = Object.keys(table);
    if (key_list.length === 0) {
        return [];
    }
    if (key_list[0] === '1' && key_list[key_list.length - 1] === String(key_list.length)) {
        key_list.sort(function (a, b) {
            return Number(a) - Number(b);
        });
        var result = [];
        for (var key of key_list) {
            if (typeof table[key] === 'object') {
                result.push(convertLuaTable(table[key]));
            } else {
                result.push(table[key]);
            }
        }
        return result;
    } else {
        for (var [key, value] of Object.entries(table)) {
            if (typeof value === 'object') {
                table[key] = convertLuaTable(value);
            } else {
                table[key] = value;
            }
        }
    }
    return table;
}
</pre></div>
</div>

==addBodyClass==
本函数可以为页面的<code>Body</code>元素添加新的class，可用于编写特定类型页面的样式。添加的class只支持英文、数字、减号和下划线。
<pre>
mw.huiji.addBodyClass(className)
</pre>

该功能也可以使用解析器函数<code>addBodyClass</code>实现，格式如下
<pre>
{{#addBodyClass:className1|className2|className3|...}}
</pre>

此外，JavaScript也可以通过<code>mw.config.get('wgExtraBodyClass')</code>获取到额外的class数据

==loadJson==
将一个Data命名空间（3500）的页面作为Json加载，使用方法
<pre>
local resultJson = mw.huiji.loadJson(title)
</pre>

title必须为<code>Data:XXXX.json</code>，也可以省略为<code>XXXX</code>

如果出现错误，会返回一个包括<code>error</code>键值的table
<pre>
{
    error = 'error message'
}
</pre>

==flattenTable==
将一个多层table转为二元table
<pre>
local newTable = mw.huiji.flattenTable(table)
</pre>

==padLeft/padRight==
在一个数字或是字符串左侧或右侧填补内容到指定长度
<pre>
local newStr = mw.huiji.padLeft(str, len, char)
local newStr = mw.huiji.padRight(str, len, char)
</pre>

{|class=wikitable
!参数||类型||说明
|-
|str||字符串或是数字||需要处理的字符串或是数字
|-
|len||整数||需要处理后达到的长度
|-
|char||字符||填充的字符，字符串默认是空格，数字默认是0
|}

==inArray==
检查一个值是否在指定的Array（数字索引的table）中出现
<pre>
local result = mw.huiji.inArray(value, array)
</pre>
