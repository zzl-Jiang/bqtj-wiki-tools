==nil==
<code>nil</code>是Lua语言中的<code>空值</code>。

所有未赋值过的变量，都将返回<code>nil</code>。

为一个变量赋值<code>nil</code>相当于删除了这个变量，主要用于删除[[#table|table]]里的变量。

<pre>
local p = {}

function p.foo( frame )
    return a  --因为a并未被赋值过，所以其值为nil
end

return p
</pre>
调用以上模块的foo函数，将会返回<code>nil</code>。

==boolean==
布尔值类型只有两个值：<code>true</code>和<code>false</code>，注意这2个值的所有字母均为小写。

布尔值会作为[[../运算符#关系运算符|关系运算]]的结果，或用于[[../运算符#逻辑运算符|逻辑运算]]之中。

在Lua中，只有<code>false</code>和<code>nil</code>会被视为“假”，其他值均为“真”（包括0）。

{{新手帮助
|关系运算是指两个值之间的关系，例如<code>5 > 10</code>的结果就是<code>false</code>。<br>
逻辑运算是指对布尔值进行运算，Lua中的逻辑运算包括<code>and</code>（与）、<code>or</code>（或）和<code>not</code>（非），例如<code>true and true</code>，结果是<code>true</code>。<br>
更多介绍请参考[[../运算符|运算符]]。

==number==
Lua的数值类型数据，存储时均为[http://baike.baidu.com/link?url=V23ld3E7O-ziUqw4P_gQeu4Gp4cikHIjuAWuEalW4z8IUN73H1w-JoRY99wn1HVk2R9YllOlBj1C9HJGVDc-JjY1KtgYetPElUIFgmUg5owfg1M9vrjyI77Jhj1vqnikbwpK1i_SBsHl1CsWn2xcc_ 双精度浮点数（double）]。

使用时，如果数值实际为整数（小数点后均为0），则该数值会被视为整数，否则视为浮点数。数值可以使用科学计数法存储。

以下均为有效的数值类型数据：
<pre>
num = 5
num = 5.2
num = 5.0  -- 会被视为5
num = 5e3  -- 使用了科学计数法，即5*10^3=5000
num = 5e+3  -- 与上例结果相同，上例为省略了正号的结果
num = 5e-3  -- 即5*10^-3 = 0.005
</pre>

数值型可以使用各种[[../运算符#算术运算符|算术运算符]]。

函数<code>tonumber (e [, base])</code>可以将参数<code>e</code>转换为<code>number</code>类型。参数<code>base</code>可以指定参数<code>e</code>的进制数，默认是10（十进制）。转换成功的话，将会返回<code>number</code>类型数据，失败的话将会返回<code>nil</code>。例如：
<pre>
tonumber("100")  -- 结果为100，变量类型从string转变成number
tonumber("100", 2)  -- 结果为4，把"100"视为二进制数字进行转换
tonumber("1e2") -- 结果为100，即 1*10^2 = 100
tonumber("1e2", 2) -- 结果为nil，因为科学计数法只对十进制有效
tonumber("max100") -- 结果为nil，因为字符串中拥有无法转成数字的内容（max）
tonumber("200", 2) -- 结果为nil，因为二进制中只能存在1和0，所以2是非法字符，无法转换
</pre>

==table==

Lua中的table是一种关联性的数据结构，使用键值对应一个任意一个数据类型，通过键值可以索引到对应的数据。

除了可以实现其他语言中数组和字典的功能外，Lua中的模块（module）和对象（Object）也是由table来实现的。

具体请参考以下页面的详细说明：
*[[../表|表]]：整体介绍table的功能
*[[../模块|模块]]：介绍在Mediawiki中，使用table实现模块（Module）的功能
*[[../面向对象|面向对象]]：介绍table实现对象（Object）的功能
