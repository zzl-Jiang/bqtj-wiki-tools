==2017年更新日志==
<h4>2017年12月15日 v0.3.27</h4>
<ul>
<li>“批量操作页面”模式：</li>
<ol><li>修正读取页面内容时，标题中含有特殊符号的情况下，请求失败。该功能涉及解析、保存和空编辑刷新。</li>
<li>修正了一个Bug：保存源代码到文本时，如果页面不属于任何命名空间，保存的文件将不会添加“.wiki”后缀。</li>
</ol>
</ul>
<h4>2017年12月13日 v0.3.26</h4>
<ul>
<li>新增“批量移动”模式：</li>
<ol><li>该模式会将指定Excel文件第一个工作表中的第一列当作原始页面名，将页面移动到对应的第二列的页面名里。</li>
</ol>
</ul>
<h4>2017年11月15日 v0.3.25</h4>
<ul>
<li>“以文本更新”模式：</li>
<ol><li>会将后缀为.html的文件上传到Html命名空间中</li>
</ol>
<li>“批量操作页面”模式：</li>
<ol><li>保存源代码到文本时，会将Html命名空间中的条目，保存为.html后缀</li>
</ol>
</ul>
<h4>2017年10月23日 v0.3.23</h4>
<ul>
<li>“批量操作页面”模式：</li>
<ol><li>解析模板时，如果出现Sheet名只有大小写不同的情况，将会给后续大小写不同的版本添加额外编号</li>
</ol>
</ul>
<h4>2017年8月7日 v0.3.21</h4>
<ul>
<li>“批量操作页面”模式：</li>
<ol><li>使用SMW查询时，每次会请求尽量多的数据，并修正了一个错误。</li>
</ol>
</ul>
<h4>2017年7月28日 v0.3.20</h4>
<ul>
<li>“上传Excel文件（JSON）”模式：</li>
<ol><li>新增该模式，该模式工作原理与模板基本相同，只是将Excel文件转成json文件上传，用于适配于新版DragonPit中的json数据存储格式。单元格中可以写Array或是Object。</li>
</ol>
<li>“以文本更新”模式：</li>
<ol><li>新增了对“.json”文件的支持，遇到该类文件时，会为其添加“Data:”开头，并进行上传。</li>
</ol>
</ul>
<h4>2017年7月25日 v0.3.19</h4>
<ul>
<li>登录模块</li>
<ol><li>适配了新版Mediawiki的登录模式</li>
</ol>
<li>“以文本更新”模式：</li>
<ol><li>“刷新缓存”功能会正确的在更新操作全部结束之后，再进行刷新了</li>
</ol>
</ul>
<h4>2017年7月20日 v0.3.17</h4>
<ul>
<li>“上传Excel文件（模板）”模式：</li>
<ol><li>修正了读取到在1900年3月1日之前的日期时，程序会崩溃的BUG</li>
</ol>
<li>“批量删除 / 恢复”模式：</li>
<ol><li>读取的文件列表可以使用文本文件了（UTF-8编码），每行一个页面名</li>
</ol>
<li>“批量操作页面”模式：</li>
<ol><li>选择需要操作的页面列表中，Excel模式改为文件列表模式。可以使用UTF-8编码的文本文件读取页面列表</li>
<li>“保存条目列表”保存的文本是UTF-8编码的，如果使用记事本进行修改调整，会自动保存成UTF-8+导致第一行的名称出现一些问题，请务必注意。</li>
<li>“解析”操作添加了一个新的选项“使用已有的表头”，该选项默认勾选。勾选该选项的情况下，如果保存目标文件存在，将会读取目标文件中的表头，用来作为基础表头。该功能用来保证表头顺序</li>
</ol>
</ul>
<h4>2017年7月17日 v0.3.15</h4>
<ul>
<li>“更新Lua”模式：</li>
<ol><li>该模式与“以文本更新”模式功能重叠，经过代码调整，现在该功能合并入“以文本更新”模式。</li>
</ol>
<li>“以文本更新”模式：</li>
<ol><li>添加了原来“更新Lua”模式中的“包括子目录”、“将子目录视为子页面”、更新完后“刷新缓存”三个功能，同时也支持识别Lua文件上传</li>
</ol>
<li>“批量操作页面”模式：</li>
<ol><li>“保存”到文本时，添加了一个新选项“将子页面保存成子目录”。</li>
</ol>
</ul>

<h4>2017年7月13日 v0.3.12</h4>

<ul>
<li>“批量操作页面”模式：</li>

</ol>

<ol><li>“刷新缓存”功能修正了会崩溃的Bug。</li>

<h4>2017年6月12日 v0.3.6</h4>
<ul>
<li>“读取数据”模式重新命名为“批量操作页面”模式：</li>
<ol><li>通过API刷新页面缓存：增加了一个调节单次申请次数的功能，如果申请刷新的页面中有许多大量时间生成的页面时，会导致刷新请求总是超时而无法继续。此时请通过该功能调低单次请求数量。</li>
<li>重写了“解析模板数据”功能：新的解析模板数据功能，会将页面中所有模板都解析到一个Excel工作薄（xlsx格式）中，不同的模板会保存到不同的工作表里，方便使用者从Wiki中将其他用户手工更新过的数据复制回本地进行加工。</li>
</ol>
<li>“上传Excel文件（模板）”模式：</li>
<ol><li>“只替换模板内容模式”调整：不再依赖注释<nowiki><!--Template [Name] end--></nowiki>，现在会替换页面中第一个同名模板。</li>
<li>该功能生成的页面内容：因为上面的调整，现在页面不再自动生成注释<nowiki><!--Template [Name] end-->。</nowiki></li>
</ol>
</ul>
