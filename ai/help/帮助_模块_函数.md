函数<code>function</code>是Lua中的一种特殊[[../数据类型|数据类型]]。

主要是为了处理一部分特定工作（尤其是需要重复进行的工作）时使用的功能。

Lua提供了很多内建函数，也可以自行编写函数来完成某些操作。

函数对于Lua的价值，类似[[Help:模板|模板]]对于Mediawiki的价值。

==编写函数==

请参考下面的例子和注释，理解函数的编写方式

函数默认会声明为全局函数，添加<code>local</code>可以将其声明为局部函数。

<pre>
function 函数名(参数列表)
  执行代码
end

-- 与上面等价的另外一种基本声明方式
函数名 = function (参数列表) 
  执行代码
end

-- 以下声明方式将声明一个局部函数
local function 函数名(参数列表)
  执行代码
end
</pre>

==参数==

函数可以预设0个或多个参数，当有预设参数位置时，调用函数时就可以传入对应数量的参数。

一般调用函数时，参数需要用一组小括号（<code>( )</code>）表示。

不过，有一种特殊情况是，传入的参数有且仅有一个<code>table</code>的时候，可以不使用<code>({...})</code>，改用<code>{...}</code>（省略掉小括号）。

<pre>
-- 预设了3个参数位置，分别命名为a, b和c
function test(a,b,c)
  mw.log(a+b+c)
end

test(1,2,4)
-- 结果
7

</pre>

当传入参数和预设参数位置数量不一样时：
*如果传入参数较多：多余的参数将被舍弃
*如果预设参数位置较多：不足的参数，将赋值<code>nil</code>

==可变参数==

有时我们也不知道可能传入多少个参数，这个时候可以使用可变参数<code>...</code>（三个点），这些不知数量的参数将会存为一个数组，名称为<code>arg</code>

<pre>
function test(...)
  local result = 0
  for i in ipairs(arg) do
    result = result + i
  end
  mw.log(result)
end

test(1,2,3,5,6,7,3,10)

-- 结果
36
</pre>

在可变参数之前，还可以指定若干个普通参数位置。

==返回值==

函数可以使用<code>return</code>设置返回值，传递运算结果给上级。

可以同时返回多个值，返回多个值的时候，接收处也需要设置多个变量来接收多个返回值。

<pre>
function test(...)
  local result = 0
  for i in ipairs(arg) do
    result = result + i
  end
  return 
end

local x = test(1,2,3,5,6,7,3,10)
mw.log(x)
-- 结果
36
</pre>
