字符串是Lua语言中，用来存储文本类型数据的一种[[../数据类型|数据类型]]。

==表示方式==

字符串可以使用三种方式表示：
*两个英文半角单引号<code>'</code>之间的一串字符
*两个英文半角双引号<code>"</code>之间的一串字符
*一组成对的英文半角双方括号<code><nowiki>[[</nowiki></code>和<code><nowiki>]]</nowiki></code>之间的一串字符

需要使用一组半角单引号或是一组半角双引号来表示。

举例：
<pre>
string = "this is a pit!"  -- 正确
string = 'this is a pit!'  -- 正确
string = this is a pit!  -- 错误，字符串前后没有引号
string = "this is a pit!'  -- 错误，字符串前后的引号需要一致（都是单引号或是都是双引号）
string = “this is a pit!”  -- 错误，引号必须是英文半角引号，不能使用中文全角引号
string = [[
欢迎来到HuijiWiki！
这里只有坑、坑和坑，
祝你挖的愉快！
]]  -- 正确，不过需要注意的是：该段文本中的换行，在Mediawiki中也会被解析成一个空格
</pre>

==转义符号==
转义符用于不能直接显示的字符，在Medaiwiki中，主要会用到的是以下几种转义符
{| class="wikitable"
!转义字符||转义结果||说明
|-
|<code>\\</code>||<code>\</code>||因为转义字符是以<code>\</code>开始的，所以当需要显示<code>\</code>时，就需要进行一次转义
|-
|<code>\'</code>||<code>'</code>||详见后面的例子
|-
|<code>\"</code>||<code>"</code>||详见后面的例子
|-
|<code>\n</code>||换行符||需要注意的是，这个换行符和在wikitext中写入一个回车是同样的效果，也就是说，当只出现一个换行符时，会被Mediawiki转成一个空格；而连续出现两个换行符时，则会另起一个新的<code>p</code>标签
|}

字符串中如果需要出现引号的话，可以使用另外一种引号来表示字符串。如果两种引号都需要出现的话，则需要使用上面提到的转义符号。例如：
<pre>
string = "this is a "pit"!"  -- 错误，字符串中出现了双引号，干扰了程序的判断
string = 'this is a "pit"!'  -- 正确，字符串中出现了双引号，所以改用单引号来表示字符串
string = "this is a \"pit\"!"  -- 正确，\"会在使用时，被当作"处理，而且不会干扰程序将此段内容判断为一个字符串
</pre>

==运算符==

字符串可以使用[[../运算符#算术运算符|算术运算符]]，Lua会尝试将字符串转成<code>number</code>型后再进行运算，如果转换失败，将会出错。
<pre>
"5" + 10  -- 结果为15
"5" + "10" -- 结果为15
"5 + 10" -- 结果为"5 + 10"，因为运算符被当作字符串中的字符了
"max" + 10 -- 会报错，因为max转换成number型时会返回nil，nil不能和10进行“+”运算，所以会报错
</pre>

字符串还可以使用以下两种运算符：
<pre>
-- 字符串连接符：“..”（两个连续的英文半角点）
-- 该运算符会将两个string连接成一个新的string
string = "this is ".."a pit!"  -- 结果为 "this is a pit!"

-- 长度运算符：“#”（英文半角井号）
-- 该运算符可以获得字符串的长度
-- 不过因为中文字符编码的问题，每个中文字符获得的长度并不是1，所以当字符串中包含中文，需要获取长度的时候，请使用后面介绍的字符串操作mw.ustring.len(s)
string_length = #"this is a pit!"  -- 结果为 14
</pre>

==转换为字符串==

函数<code>tostring(e)</code>可以将参数<code>e</code>转换为<code>string</code>类型。

该函数实际上是调用参数<code>e</code>的元方法<code>__tostring</code>，所以当<code>e</code>没有这个元方法时，将无法使用。

例如：
<pre>
tostring(100)  -- 结果为"100"，数据类型从number转变成string
</pre>

==字符串操作==

Lua提供了<code>String</code>库，来对字符串进行各种操作，不过该库并不支持<code>UTF-8</code>编码，所以Mediawiki又提供了一个<code>Ustring</code>库来替代<code>String</code>库的功能。

在Mediawiki中使用Lua时，尽量使用<code>Ustring</code>库进行字符串操作，以避免碰到中文时出错。

本处介绍的字符串操作，都是编写Wiki中比较容易用到的，更多字符串操作请参考[https://www.mediawiki.org/wiki/Extension:Scribunto/Lua_reference_manual#Ustring_library 这里]。

接受的格式代号如下表，注意大小写是不同的符号：
{| class="wikitable"
!格式符号||数据类型||说明
|-
|<code>%s</code>||<code>string</code>||将字符串格式化后显示
|-
|<code>%q</code>||<code>string</code>||<span class="btn-danger" style="padding: 2px 5px;">不适合初学者</span> 将字符串转化成可安全被Lua编译器读入的格式
|-
|<code>%d</code> / <code>%i</code>||<code>number</code>||将数字转化成有符号（signed）的整数格式
|-
|<code>%f</code>||<code>number</code>||将数字转化成浮点数格式
|-
|<code>%c</code>||<code>number</code>||将数字转化为ASCII码表中对应的字符
|-
|<code>%u</code>||<code>number</code>||<span class="btn-danger" style="padding: 2px 5px;">不适合初学者</span> 将数字转化成无符号（unsigned）的整数格式
|-
|<code>%o</code>||<code>number</code>||将数字转化成八进制数字
|-
|<code>%x</code> / <code>%X</code>||<code>number</code>||将数字转化成十六进制数字，<code>%x</code>使用小写字母，<code>%X</code>使用大写字母
|-
|<code>%e</code> / <code>%E</code>||<code>number</code>||将数字转化成科学技术法格式，<code>%e</code>使用小写字母e，<code>%E</code>使用大写字母E
|-
|<code>%g</code> / <code>%G</code>||<code>number</code>||将数字转化成“科学技术法”和“浮点数”中，长度比较短的那种格式，<code>%g</code>使用小写字母e，<code>%G</code>使用大写字母E
|}

为了进一步细化，还可以在格式符号的<code>%</code>后添加下列参数。需要注意的是，参数按照下表的顺序进行读取，所以填写时要保证好顺序：
{| class="wikitable"
!参数||说明
|-
|<code>+</code>||会显示数字的正号。不添加此参数时，只有负号才会显示，添加后正号也会显示
|-
|<code>0</code>||当指定了字符串宽度的时候，数字长度不足位的时候，会使用空格填充，如果指定了<code>0</code>参数，则改为用0填充（可以参考后面的例子）
|-
|<code>-</code>||当指定了字符串宽度，并且没有指定使用0填充时，空格会在字符串的左侧（字符串右对齐），如果添加<code>-</code>参数，空格会在字符串右侧（字符串左对齐）
|-
|<code>n</code>||n需要填写一个整数。该整数会指定字符串宽度，注意这个宽度会包括正负号、小数点以及小数部分
|-
|<code>.n</code>||n需要填写一个整数，该整数会指定小数保留长度。另外也可以用来切割字符串（对<code>%s</code>使用时），但对中文支持并不好，不推荐使用
|}

示例：
<pre>
-- 格式化字符串
mw.log(mw.ustring.format('将字符串格式化进来：%s，格式化的后面文字', '文字文字'))  -- 结果："将字符串格式化进来：文字文字，格式化的后面文字"

-- 格式化整数，补位0
mw.log(mw.ustring.format('格式化日期格式为YYYY/MM/DD：%04d/%02d/%02d', 2017,7,7))  -- 结果："格式化日期格式为YYYY/MM/DD：2017/07/07"
-- %d表示只显示整数，%4d表示是一个四位的整数（不足的位数用空格补齐），%04d表示这是一个四位整数（不足的位数用0补齐）

-- 格式化小数
mw.log(mw.ustring.format('%.2f', 10))  -- 结果："10.00"
-- %f表示小数（小数点后会保留默认位），%.2f表示小数点后保留两位小数，不足的会补0

-- 综合
mw.log(mw.ustring.format('%+08.2f', 10))  -- 结果："+0010.00"
-- +表示显示数字的正号；0表示不足位时填充0；8表示字符串总宽度为8；.2表示小数部分保留2位
-- 需要注意的是宽度8包括了正号和小数点，所以数字部分只剩下6位（4位整数部分，2位小数部分）
</pre>

===匹配式===

<span class="btn-danger" style="padding: 2px 5px;">本段落介绍的内容，不适合程序语言的初学者学习</span>

Lua的匹配式（pattern），实际上是一个简化版本的正则表达式，可以用在<code>string.find</code>，<code>string.gsub</code>，<code>string.match</code>和<code>string.gmatch</code>函数中，对应到<code>Ustring</code>库，则是<code>mw.ustring.find</code>，<code>mw.ustring.gsub</code>，<code>mw.ustring.match</code>和<code>mw.ustring.gmatch</code>函数。使用的格式是'''匹配式+数量词'''。
*例如<pre>mw.ustring.match(text,"%a+") //从字符串变量text中匹配1个或者多个字母字符（总是匹配尽量多的字符）</pre>

{| class="wikitable"
!匹配式||说明||匹配式||说明
|-
|style="text-align:center"|单个字符||colspan=3|与该字符自身进行匹配，但不包括以下保留字符：<code>^ $ . [ ] * + - ?</code><br>这些保留字符如果需要进行匹配，需要在字符前加 <code>%</code>进行转义，例如 <code>%$</code>表示<code>$</code>
|-
|style="text-align:center"|<code>.</code>||colspan=3|与任意字符匹配
|-
|style="text-align:center"|<code>%a</code>||与任意字母匹配||style="text-align:center"|<code>%A</code>||与任意'''非'''字母的字符匹配
|-
|style="text-align:center"|<code>%d</code>||与任意数字匹配||style="text-align:center"|<code>%D</code>||与任意'''非'''数字的字符匹配
|-
|style="text-align:center"|<code>%w</code>||与任意字母或数字匹配||style="text-align:center"|<code>%W</code>||与任意'''非'''字母且'''非'''数字的字符匹配
|-
|style="text-align:center"|<code>%c</code>||与任意控制符匹配，例如<code>\n</code>||style="text-align:center"|<code>%C</code>||与任意'''非'''控制符匹配
|-
|style="text-align:center"|<code>%l</code>||与任意小写字母匹配||style="text-align:center"|<code>%L</code>||与任意'''非'''小写字母的字符匹配
|-
|style="text-align:center"|<code>%u</code>||与任意大写字母匹配||style="text-align:center"|<code>%U</code>||与任意'''非'''大写字母的字符匹配
|-
|style="text-align:center"|<code>%p</code>||与任意标点匹配||style="text-align:center"|<code>%P</code>||与任意'''非'''标点的字符匹配
|-
|style="text-align:center"|<code>%s</code>||与空白字符匹配||style="text-align:center"|<code>%S</code>||与任意'''非'''空白字符匹配
|-
|style="text-align:center"|<code>%x</code>||与任意十六进制数字匹配||style="text-align:center"|<code>%X</code>||与任意'''非'''十六进制数字匹配
|-
|style="text-align:center"|<code>%z</code>||与任意代表0的字符匹配||style="text-align:center"|<code>%Z</code>||与任意'''不'''代表0的字符匹配
|-
|style="text-align:center"|<code>[描述]</code>||描述可以填写多个字符符号<br>该匹配式表示与多个字符符号任意一个匹配的字符||style="text-align:center"|<code>[^...]</code>||描述可以填写多个字符符号<br>该匹配式表示与多个字符符号'''都不'''匹配的字符
|}

以上匹配式可以用来代表各类字符，匹配的时候，会根据'''数量词'''而选择不同长度的字符进行匹配，匹配数量的多少根据匹配式后面的符号决定：
{| class="wikitable"
!数量词||说明
|-
|style="text-align:center"|无符号||匹配1个符合匹配式的字符
|-
|style="text-align:center"|<code>*</code>||匹配0个或是多个该类字符，总是匹配尽量多的字符（贪婪模式）
|-
|style="text-align:center"|<code>+</code>||匹配1个或是多个该类字符，总是匹配尽量多的字符（贪婪模式）
|-
|style="text-align:center"|<code>-</code>||匹配0个或是多个该类字符，总是匹配尽量少的字符（非贪婪模式）
|-
|style="text-align:center"|<code>?</code>||匹配0个或是1个该类字符
|}

匹配式还可以进行'''边界匹配'''：
{| class="wikitable"
!边界匹配符||说明
|-
|style="text-align:center"|<code>^</code>||当该符号出现在开头时，表示匹配式从字符串的开头进行匹配。出现在其他位置时，仅作为该符号的匹配式使用，无特别含义
|-
|style="text-align:center"|<code>$</code>||当该符号出现在结尾时，表示匹配式会匹配到字符串的结尾。出现在其他位置时，仅作为该符号的匹配式使用，无特别含义
|-
|style="text-align:center"|<code>%bxy</code>||x和y为额外的两个任意字符，该匹配式将匹配从x到y之间的字符（x和y的数量必须平衡，例如出现<code>xxaaybby</code>时，会匹配到<code>xxaaybby</code>而不是<code>xxaay</code>）
|}

匹配式还可以进行'''捕捉'''，可以用于<code>string.gsub</code>和<code>mw.ustring.gsub</code>的替换时使用：
{| class="wikitable"
!捕捉相关符号||说明
|-
|style="text-align:center"|<code>( )</code>||一对半角括号之间为一次捕捉
|-
|style="text-align:center"|<code>%n</code>||其中n为一个数字，这个数字从1开始，根据捕捉的数量依次递增（第一个捕捉到的字符串<code>%1</code>，第二个为<code>%2</code>…），用于替换的字符串中使用
|}

===匹配查找字符串===

<span class="btn-danger" style="padding: 2px 5px;">本段落介绍的内容，不适合程序语言的初学者学习</span>

{| class="wikitable"
!<code>String</code>库写法||<code>Ustring</code>库写法||说明
|-
|<code>string.match(s, pattern, init)</code>||<code>mw.ustring.match(s, pattern, init)</code>||从字符串<code>s</code>中，第<code>init</code>位开始，查找匹配式<code>pattern</code>，将找到的第一个结果中的捕获结果作为返回值，如果没有设置捕获，则返回匹配到的字符串。
|}

{| class="wikitable"
!colspan=4|参数
|-
!参数||类型||style="width:50px;"|必要||说明
|-
!s
|<code>string</code>
|style ="width:4em" |<span class="btn-primary" style="padding: 2px 5px;">必填</span>
|原始字符串，函数在该字符串中进行匹配
|-
!pattern
|<code>string</code>
|style ="width:4em" |<span class="btn-primary" style="padding: 2px 5px;">必填</span>
|用于查找的[[#匹配式|匹配式]]
|-
!init
|<code>number</code>
|style ="width:4em" |<span class="btn-info" style="padding: 2px 5px;">可选</span>
|查找的起始位置，默认为1，可以填写负数
|-
!colspan=4|返回值
|-
!序号||类型||colspan=2|说明
|-
!不定数量
|<code>string</code>
|colspan=2|如果在<code>pattern</code>中指定了捕获，则会根据捕获数量返回同数量的返回值；如果没有指定捕获则只返回符合条件的字符串；如果没有符合条件的字符串则返回<code>nil</code>
|}

示例：
<pre>
local text = 'xxa ay bby'
mw.log(mw.ustring.match(text, '%s(%w*)%s'))  -- 结果：ay，匹配式的是“空白”、“0个或多个字母或数字”、“空白”连在一起，捕获是中间的“0个或多个字母或数字”，原字符串中只有“ ay ”符合匹配
</pre>
