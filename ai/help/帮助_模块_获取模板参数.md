本章节主要解释如何在lua中获得wiki页面传入的参数。

==方法一：自模板取用参数==
这种方法的传递链是页面——模板——模块函数，总共分三步，需要在调用<nowiki>{{</nowiki>#invoke:}}的模板中做一次参数传递，参考下面的例子：
;页面部分
<pre>
{{_yourTemplate|24|tool|name=工具}}
</pre>

;template 部分（假设模板名称为<code>模板:_yourTemplate</code>）
<pre>
{{#invoke:_yourMoudule|_test|{{{1|}}}|{{{2|}}}|{{{name|DefaultName}}}}}
</pre>

;module 部分（假设模块名称为<code>模块:_yourMoudule</code>）
<pre>
local p = {}


function p.test(frame)
  local args = frame.args
  local <some args> = args[1]
  local <some args> = args[2]
  local <some args> = args[3]
  ...
  
end

return p
</pre>

最终p.test()的变量取自mw的全局object——“frame”下的args（一个表），这个表由调用<nowiki>{{</nowiki>#invoke:}}的模板中手动构造，args[1]是<nowiki>{{{1|}}}</nowiki>、args[3]是<nowiki>{{{name|DefaultName}}}</nowiki>

==方法2：自页面取用==
这种方法会直接'''跳过'''模板<nowiki>{{</nowiki>#invoke:}}函数中传递的参数。

*需要灰机基础安装包中预设的Lua模块——[[模块:Arguments]]，用以在一个[[帮助:模板|模板]]中的模块内，获得模板的全部参数。您可以在任何时候方便的调用它。
**如果您的站点中没有这个module，可以前往[[templatemanager:模块:Arguments]]手动搬运

下面是一个简单的例子：

;页面调用代码：
<pre>
{{_yourTemplate
|24
|type = tool
|name = 灰机wiki}}
</pre>

;template内容（假设模板名称为<code>模板:_yourTemplate</code>）：
<pre>
{{#invoke:_yourMoudule|test}}
</pre>


;module 部分（假设模块名称为<code>模块:_yourMoudule</code>）：
<pre>
local p = {}
local getArgs = require('Module:Arguments').getArgs

function p.test(frame)
  local args = getArgs(frame)
  local <some args> = args[1]
  local <some args> = args["type"]
  local <some args> = args['name']
  ...
end

return p
</pre>

最终p.test()的变量取自页面中<nowiki>{{_yourTemplate}}</nowiki>的所有参数（一个表），这个表由调用无需经过模板传参构造。

调用的结果：args[1]是模板的第一个[[help:模板参数|序号参]]，args["type"]是模板的命名参|type = tool，以此类推。


==对比==
{| class="wikitable"
|-
! 方法 !! 传递层级 !! 需要构造 !! 需要require包 !! 优点
|-
| 方法一 || 3 || 是 || 否 || 可以在template中修改、处理参数，适合老模板改造，适用于序号参为主，命名参数较少（或没有）、参数名称可控的模板
|-
| 方法二 || 2 || 否 || 是 || 原样传递模板参数，容错率较高，对奇葩参数和typo的处理灵活性较高，适用于参数茫茫多，参数名不可预知的调用场景，比如infobox、navbox
|}


==备注==
两者可以同时使用并生效，具体例子就不列出来了，可以自行实验
<pre>
local p = {}
local getArgs = require('Module:Arguments').getArgs

function p.test(frame)
  local args1 = getArgs(frame)
  local args2 = frame.args
  local <some args> = args1["type"]
  local <some args> = args2['name']
  ...
end

return p
</pre>
